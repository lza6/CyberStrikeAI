3. 关键设计决策（直觉）

3.1 确定性安全层叠在 LLM 之前（ADR-0006）

shellsafe/scope/HIGH_IMPACT/TurnLimiter 四闸全部纯函数、无 LLM 在环，零延迟零 token。移植自 Pentest-Swarm-AI/mcpstrike/strix，Go 重写为纯函数（"逻辑各语言相通，重构而非依赖"）。

3.2 skill 供应链双闸（caveman 思想）

skills-lock.json SHA256 锁（28 skill，篡改/缺失/未锁定三型违规）+ verbs-gate 工具引用漂移门（246 真实工具全集，扫描 SKILL.md 引用幽灵工具）。启动时 Verify 违规只 Warn 不阻断（生产兼容）。

3.3 Cache-Aside 降级哲学（ADR-0002）

Redis 是可选依赖：cache.driver: memory（默认）零外部依赖；redis 连接失败自动降级 memory + Warn，不阻断启动。用户"单文件不是硬约束"，Redis 引入不破坏桌面定位。

3.4 Electron 原生外壳增强（ADR-0005）

托盘常驻（显示主窗/打开Web/重启后端/退出 + 双击恢复 + 气泡）、启动画面（三阶段状态文案）、单实例锁（防双开端口冲突）、关窗最小化到托盘（不退出）、原生错误对话框（重试/打开日志/退出）。
